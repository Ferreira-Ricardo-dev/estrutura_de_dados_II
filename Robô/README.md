# 🌡️ Monitoramento de Temperatura

Programa em **Python** que simula 5 sensores com 24 leituras de temperatura cada.

## Funcionalidades

- Gera temperaturas aleatórias entre 20 °C e 40 °C.
- Calcula a média dos sensores.
- Calcula a média geral.
- Identifica a maior temperatura, sensor e horário.
- Conta leituras acima de um limite definido pelo usuário.

## Tecnologias

- Python 3
- Biblioteca `random`
